# axioma

Системная подготовка к ОГЭ и ЕГЭ  по математике и информатике

Помогаю закрыть пробелы, разобраться в школьной программе  и уверенно решать задания базового и повышенного уровня.

---

### Что получаешь

- Чёткую структуру подготовки без хаоса и «просто решаем варианты»
- Понимание задач, а не заучивание шаблонов
- Регулярную практику с разбором ошибок
- Рост балла за счёт системной работы, а не случайных удач

### Олимпиадная математика

Если нужен первый вход в олимпиады — помогаю подготовиться  к школьному и муниципальному этапам. Спокойно, по шагам, без перегруза.

### Подход

Системность + понимание + регулярная практика. Именно это даёт стабильный результат.
